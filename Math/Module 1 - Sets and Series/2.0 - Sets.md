# 2.0 - Sets

> [!def] Set
> A **set** is an unordered collection of distinct objects, called **elements**. We write $x\in A$ if $x$ is an element of $A$, and $x\notin A$ otherwise.
> $$A=\{x\mid P(x)\}$$

^742d66

> [!def] Subset
> $A$ is a **subset** of $B$ if every element of $A$ is also an element of $B$.
> $$A\subseteq B\iff(x\in A\implies x\in B)$$

^734f1e

## Set Operations

> [!def] Union
> The **union** of $A$ and $B$ is the set of elements in $A$ or $B$ or both.
> $$A\cup B=\{x\mid x\in A\text{ or }x\in B\}$$

^9a3782

> [!def] Intersection
> The **intersection** of $A$ and $B$ is the set of elements in both $A$ and $B$.
> $$A\cap B=\{x\mid x\in A\text{ and }x\in B\}$$

^a1b2c3

> [!def] Set Complement
> The **complement** of $A$ relative to a universal set $U$ is the set of elements in $U$ not in $A$.
> $$A^{c}=U\setminus A=\{x\in U\mid x\notin A\}$$

^b2c3d4

> [!def] Set Difference
> The **difference** of $A$ and $B$ is the set of elements in $A$ but not in $B$.
> $$A\setminus B=\{x\mid x\in A\text{ and }x\notin B\}$$

^c3d4e5

> [!def] Cartesian Product
> The **Cartesian product** of $A$ and $B$ is the set of all ordered pairs $(a,b)$ with $a\in A$ and $b\in B$.
> $$A\times B=\{(a,b)\mid a\in A,\ b\in B\}$$

^f6a7b8

> [!def] Cardinality
> The **cardinality** $|A|$ of a set $A$ is the number of elements in $A$. Two sets are **equinumerous** if there exists a bijection between them.

^a7b8c9

## Special Sets

> [!def] Empty Set
> The **empty set** $\emptyset$ is the unique set containing no elements.
> $$\emptyset=\{\},\quad |{\emptyset}|=0$$

^d4e5f6

> [!def] Power Set
> The **power set** of $A$ is the set of all subsets of $A$.
> $$\mathcal{P}(A)=\{S\mid S\subseteq A\},\quad|\mathcal{P}(A)|=2^{|A|}$$

^e5f6a7

> [!def] Disjoint Sets
> Two sets $A$ and $B$ are **disjoint** if they share no elements.
> $$A\cap B=\emptyset$$

^b8c9d0

> [!def] Partition
> A **partition** of a set $A$ is a collection of non-empty disjoint subsets $\{A_{i}\}$ whose union is $A$.
> $$\bigsqcup_{i}\,A_{i}=A,\quad A_{i}\cap A_{j}=\emptyset\ (i\neq j)$$

^c9d0e1
