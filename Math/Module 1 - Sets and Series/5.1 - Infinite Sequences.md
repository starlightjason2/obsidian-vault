# 5.1 - Infinite Sequences

> [!definition] Infinite Sequence
An infinite sequence is an infinite ordered list of numbers $\{a_{1},\dots,a_{n}\dots\}$ that can be defined by a [[3.1 - Scalar Functions#^f874ea]] or a recurrence relation. For a sequence $\{a_{n}\}=\{ \dots\}$, the function $a_{n}$ gives us the value of the sequence at index $n$.

^cb5e23

## Convergence

> [!definition] Convergent Sequence
> If the [[3.4 - Limits#^1a2846]] of an [[#^cb5e23]] $\{a_n\}$ exists and evaluates to some finite value $L$, then we say that this sequence **converges** to $L$.
> $$\lim_{ n \to \infty }a_{n}=L$$

^654999

> [!definition] Divergent Sequence
> If an [[#^cb5e23]] $\{a_n\}$ is not a [[#^654999]], it is a **divergent** sequence. In other words, $\lim_{n\to\infty}{a_{n}}$ does not exist or converges to infinity.
> $$\lim_{ n \to \infty }a_{n}\text{ DNE or}\lim_{n\to\infty}{a_{n}}=\pm \infty$$

^c9939e

### Cauchy Sequences

> [!definition] Cauchy Sequence
> An [[#^cb5e23]] $\{a_n\}$ is a **Cauchy Sequence** if the [[2.1 - Vectors#^57eeb7]] $\left\lvert{a_{n}-a_{m}}\right\rvert$ vanishes as each $n,m\to\infty$.
> $$\forall\,\varepsilon>0,\quad\exists\,N:\quad n,m>N\implies \left\lvert{a_{n}-a_{m}}\right\rvert<\varepsilon$$

^42955f

### Arithmetic Sequences

> [!definition] Arithmetic Sequence
> An **arithmetic** [[#^cb5e23]] $\{a_{n}\}$ increments by a *fixed amount* $b$ for each index.
>
> $$\{a_{n} \} \text{ is arithmetic}\iff a_{n} = a_{1}+b(n-1)\iff\begin{cases}
a_{1},&n=1 \\
a_{n}=a_{n-1}+b,&n>1
\end{cases}$$

### Geometric Sequences

> [!def] Geometric Sequence
> A **geometric** [[#^cb5e23]] $\{a_{n}\}$ scales by a fixed *common ratio* $r$ for each index.
> $$\{a_{n} \}\text{ is geometric}\iff a_{n} =a_{1}\, r^{n-1}\iff\begin{cases}
a_{1} \\
a_{n}=r\,a_{n-1},&n>1
\end{cases}$$

^33b728

#### Convergence and Divergence of Geometric Sequences

Notice that a geometric sequence will **converge** if $|r|<1$ and **diverge** if $|r|\geq{1}$ . This is because if the common ratio is smaller than one, the values will keep getting smaller and smaller for subsequent numbers in the sequence. If the ratio is exactly one, the values will not grow at all. If the ratio is greater than one, it means the values will keep growing out to infinity. 

> [!theorem] Convergence and Divergence of Geometric Sequences
> Given a [[#^33b728]] $\left\{a_{n}\right\}$, if [[3.6 - Complex Numbers#^c7e22f]] of the common ratio $\left\lvert{r}\right\rvert\geq1$, then $\left\{a_{n}\right\}$ is a [[#^c9939e]]. Otherwise, $\left\{a_{n}\right\}$ is a [[#^654999]].
> $$a_{n} =a_{1}\,r^{n-1}\implies \begin{cases}
\{a_{n} \}\text{ converges} & \left\lvert{r}\right\rvert< 1 \\
\{a_{n} \}\text{ diverges} & \left\lvert{r}\right\rvert\geq1
\end{cases}$$

## Bounded Sequences

Sequences that never go above or below a certain value are bounded.

> [!definition] Bounded Infinite Sequence
> An [[#^cb5e23]] is bounded above by $M$ and/or below by $N$ if $N\leq a_{n}\leq M$ for all indexes $n$. If it is bounded both above and below, we call it a **bounded sequence**, otherwise, we call it an **unbounded sequence**.

### Monotone Sequences

> [!definition] Monotone Sequence
> A monotone sequence is an [[#^cb5e23]] $\{a_{n}\}$ that *only increases* or *only decreases* after some index $n_{0}$.

^4dfa49

> [!thm] Monotone Convergence Theorem
> If $\{a_{n}\}$ is both a [[#^499d6a]] and a [[#^4dfa49]] for all positive integers $n\geq n_{0}$, where $\exists n_{0}\in \mathbb{Z}^+$, then $\{a_{n}\}$ is also a **[[#^654999]]**.
