# 3.1.3 - Vector Fields

> [!def] Vector Field
> A **vector field** is a [[3.2 - Vector Functions#^c8839e]] mapping each [[3.2 - Vector Functions#^367268]] $\mathbf{r}\in\mathbb{R}^{3}$ to some vector.
> $$\mathbf{F}(\mathbf{r})\equiv P(\mathbf{r})\,\hat{\boldsymbol{x}}+Q(\mathbf{r})\,\hat{\boldsymbol{y}}+R(\mathbf{r})\,\hat{\boldsymbol{z}}$$

^3ea3bd

## Conservative Fields

> [!def] Conservative Vector Field
> A **conservative** [[#^3ea3bd]] $\mathbf{F}$ is the [[3.5 - Derivatives#^5bb63d]] of some **potential function** $f$.
> 
> $$\mathbf{F}(\mathbf{r})\equiv\nabla f(\mathbf{r})$$

^bf3ea9

### Properties of Conservative Fields

> [!thm] Cross-Partial Property
> If $\mathbf{F}(\mathbf{r})$ is a [[#^bf3ea9]] over a [[3.8 - Regions#^7c6cc9]], then the cross partials of each coordinate are equal. 
> 
> $$\mathbf{F}\text{ is conservative}\implies\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}, \ \frac{\partial Q}{\partial z}=\frac{\partial R}{\partial y}, \ \frac{\partial R}{\partial x}=\frac{\partial P}{\partial z}$$
>

^638ed3

`\begin{proof}`@[[#^638ed3]]
There is a function $f$ such that $\nabla f=\mathbf{F}$. Therefore, $\frac{\partial f}{\partial x}=P, \ \frac{\partial f}{\partial y}=Q$. By [[3.7 - Multiple Derivatives#^6705f1]], $f_{xy}=f_{yx}\implies P_y=Q_{x}$. Proceed similarly in $\mathbb{R}^{3}$.
`\end{proof}`


> [!thm] Circulation of a Conservative Field
> The [[3.10 - Vector Integrals#^11dd4a]] of a [[#^bf3ea9]] $\mathbf{F}$ along any closed curve $\mathbf{r}$ is $0$.
> $$\mathbf{F}\text{ is conservative}\implies\oint \mathbf{F}\cdot d\mathbf{r}=0$$


> [!thm] Path Independence of Conservative Fields
> Let $C_{1}, \ C_{2}$ be two curves with the *same end points*, represented by $\mathbf{r}_{1}, \ \mathbf{r}_{2}$. Let $\mathbf{F}$ be a [[3.3 - Vector Fields#^3ea3bd]] with a domain over a [[3.8 - Regions#^7c6cc9]].
>
> If $\mathbf{F}$ is a [[#^bf3ea9]], then the [[3.10 - Vector Integrals#^4bd53c]] of $\mathbf{F}$ over $C_{1}, \ C_{2}$ is *identical*.
> 
> $$\mathbf{F}\text{ is conservative}\implies\left( \int_{C_{1}}\mathbf{F}\cdot d\mathbf{r}_{1}=\int_{C_{2}}\mathbf{F} \cdot d\mathbf{r}_{2} \right)$$
> 

^9557c8

`\begin{proof}`@[[#^9557c8]]
Since $\mathbf{F}$ is conservative, there exists a potential function $f$. By the [[3.11 - Fundamental Theorems#^ecde04]], and because the endpoints $P_{a},\ P_{b}$ are the same for $C_{1}, \ C_{2}$,

$$
\int_{C_{1}}\mathbf{F}\cdot d\mathbf{r}_{1}=f(P_{a})-f(P_{b})= \int_{C_{2}}\mathbf{F}\cdot d\mathbf{r}_{2}
$$
`\end{proof}`

### Conservative Tests

> [!cor] The Cross Partial Test
> The **converse** of [[#^638ed3]] is true. If the cross-partial property is satisfied and $D$ is a **simply connected region**, then $\mathbf{F}$ is **conservative**.
> $$\frac{\partial P}{\partial y}=\frac{\partial Q}{\partial x}, \ \frac{\partial Q}{\partial z}=\frac{\partial R}{\partial y}, \ \frac{\partial R}{\partial x}=\frac{\partial P}{\partial z}\implies\mathbf{F}\text{ is conservative}$$

> [!cor] Path Independence Test for Conservative Fields
> The **converse** of [[#^9557c8]] is true. If $\mathbf{F}$ is *path independent* then $\mathbf{F}$ **is conservative**.
> 
> $$\left( \int_{C_{1}}\mathbf{F}\cdot d\mathbf{r}_{1}=\int_{C_{2}}\mathbf{F} \cdot d\mathbf{r}_{2} \right)\implies\mathbf{F}\text{ is conservative}$$
>


>[!thm] Curl Test for Conservative Fields
>If the [[3.6 - Vector Derivatives#^066679]] of a [[#^3ea3bd]] $\mathbf{F}$ is $0$, then $\mathbf{F}$ is a [[#^bf3ea9]].
>
>$$(\nabla \times \mathbf{F}=0)\implies \mathbf{F}\text{ is conservative}$$
>
