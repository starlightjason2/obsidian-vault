# 3.1.4 - Limits and Continuity

> [!def] Limit
> Let there be a [[3.1 - Scalar Functions#^f874ea]] $f(\mathbf{r})$. The **limit** $L=\lim_{\mathbf{r}\to \mathbf{r'}}f(\mathbf{r})$ is defined such that for any distance $\epsilon$ from $L$ there is a distance $\delta$ away from $\mathbf{r'}$ so that *any input* $\mathbf{r}$ inside the $\delta$ disk has *some output* inside the $\epsilon$ disk.
>
> $$\lim_{\mathbf{r} \to \mathbf{r'}} f(\mathbf{r}) = L \iff \forall \epsilon > 0, \  \exists \delta > 0 \text{ such that } 0 < \lvert{\mathbf{r} - \mathbf{r'}}\rvert\,< \delta \implies \lvert{f(\mathbf{r}) - L}\rvert\, < \epsilon$$
>
>

^1a2846

> [!thm] Linearity of the Limit
> The [[#^1a2846]] is a [[2.7 - Function Spaces#^3fa82b]].
>
> $\lim_{\mathbf{r}\to\mathbf{r'}}{\Big[a\,f(\mathbf{r})+b\,g(\mathbf{r})\Big]}=a\lim_{\mathbf{r}\to\mathbf{r'}}{f(\mathbf{r})}+b\lim_{\mathbf{r}\to\mathbf{r'}}{g(\mathbf{r})}$
>

> [!thm] Two Path Test for a Limit
> The [[#^1a2846]] $\lim_{\mathbf{r}\to\mathbf{r'}}{}f(\mathbf{r})=L$ is defined if $L$ does not depend on the path to reach $\mathbf{r'}$.
>
> Therefore, the contrapositive is also true, or the **limit does not exist** if there are **two different values** for **two different paths**.

## Continuity

> [!def] Continuous Function
> If the [[#^1a2846]] $\lim_{\mathbf{r}\to\mathbf{r'}}{f(\mathbf{r})}=f(\mathbf{r'})$ then $f$ is **continuous** at $\mathbf{r}=\mathbf{r'}$. If $f$ is continuous for all inputs in its domain, then it's **continuous everywhere**.

^44db3d

> [!thm] Properties of Continuous Functions
> If $f$ and $g$ both exhibit [[#^44db3d]] everywhere, then
>
> 1. $h(\mathbf{r})=f(\mathbf{r})g(\mathbf{r})$ is continuous
> 2. $h(\mathbf{r})=f(\mathbf{r})\pm g(\mathbf{r})$ is continuous
> 3. $h(\mathbf{r})=f(g(\mathbf{r}))$ is continuous
