# 3.5 - Step and Delta

## Dirac Delta

> [!def] Dirac Delta Function
> The **dirac delta** $\delta(x)$ is a distribution defined by the following properties. Let $(b<0<c)\in \mathbb{R}$.
>1. $$\delta(x)=\begin{cases}
0 & x\neq 0 \\
\infty & x=0
\end{cases}$$
> 2. $$\int_{b}^{c}\delta(x)\,dx=1$$
> 3. $$x\,\delta(x)=0$$

^017ca2

> [!def] Delta Function in $\mathbb{R}^{3}$
> A distribution located at the origin $\mathbf{r}=0$ will require a [[#^017ca2]] in each coordinate.
>
> $$\delta(x)\,\delta(y)\,\delta(z)=\delta^{3}(\mathbf{r})$$
>

^delta-function-in-mathbbr3

> [!thm] Integrating the Delta Function
> Let there be an integral with a [[#^017ca2]] $f(x)\,\delta(x-a)$ inside the integrand. The integral evaluates to $f(a)$.
>
> $$\int_{-\infty}^{\infty}f(x)\,\delta(x-a)\,dx=f(a)$$

^integrating-the-delta-function

> [!exm] Distribution with Dirac Delta
> If there is a quantity $q$ located at $\mathbf{r'}$, then we can represent the distribution $\mathbf{r}=\mathbf{r'}$ using a [[#^delta-function-in-mathbbr3]].
> $$\rho(\mathbf{r})=q\,\delta^{3}(\mathbf{r}-\mathbf{r'})$$

### Kroeneker Delta

> [!def] Kroeneker Delta Function
> The **kroeneker delta** $\delta(x)$ is a version of the [[#^017ca2]].
>$$\delta_{ij}=\begin{cases}
0 & i\neq j \\
1 & i=j
\end{cases}$$
>

## Step Function

> [!def] Step Function
> A step function $\Theta(x-a)$ changes from one constant value to another. The function "turns on" at $a\in \mathbb{R}$, with a discontinuity at $x=a$. A value of $\Theta(a)=\frac{1}{2}$ is usually chosen for symmetry.
> $$\Theta(x)=\begin{cases}
0 & x<a \\
\text{undefined} & x=a \\
1 & x>a
\end{cases}$$

^ad4b33

> [!example] Step function for an interval
> Consider a [[3.1 - Scalar Functions#^function]] $f(x)$ with a domain of $x\in[a,b]$. We can write $f(x)$ using the [[#^ad4b33]] $\Theta(x)$ with a domain of $x\in \mathbb{R}$.
> $$\Big\{f(x): \ x\in[a,b] \Big\}\equiv \Big\{f(x)\Big(\Theta(x-a)-\Theta(x-b)\Big): \ x\in\mathbb{R}\Big\}$$

> [!thm] Derivative of the Step Function
> The derivative of the [[#^ad4b33]] is the [[#^017ca2]].
>
> $$\frac{d}{dx}\Theta(x-a)=\delta(x-a)$$
