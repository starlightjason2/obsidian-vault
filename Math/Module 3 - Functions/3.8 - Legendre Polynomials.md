# 3.8 - Legendre Polynomials

> [!def] Legendre Polynomial
> The **Legendre polynomials** are an [[5.1 - Infinite Sequences#^cb5e23]] $\left\{P_{\ell}(z) \right\}, \ \ell\in \mathbb{Z}^{+}$ defined with Rodrigues' formula involving the [[3.7 - Multiple Derivatives#^nth-derivative|$\ell$th Derivative]] of $(z^{2}-1)^{\ell}$, where $z=\cos\theta$ in [[2.6 - Coordinate Sytems#^spherical-coordinates]].
>
> Note that ${1}/{2^{\ell}\ell!}$ is a normalization factor.
> $$P_{\ell}(z)=\frac{1}{2^{\ell}\ell!} \frac{d^{\ell}}{dz^{\ell}}\Big[(z^{2}-1)^{\ell} \Big]$$
> Or using the product rule on $(z^{2}-1)^{\ell}=(z-1)^{\ell}(z+1)^{\ell}=a^{\ell}b^{\ell}$:
> $$P_{\ell}(z)=\frac{1}{2^{\ell}\ell!}\sum_{i=0}^{\ell}{\binom{\ell}{i} \left( \frac{d^{\ell-i}a}{dz^{\ell-1}} \right)\left( \frac{d^{i}b}{dz^{i}} \right) }$$
>
>
>

^legendre-polynomial

> [!def] Legendre Coefficient
> The coefficients $c_{\ell}$ for the [[#^legendre-series]] of any function $f(z)\in L^{2}$ are:
> $$c_{\ell}=\frac{2\ell+1}{2}\int_{-1}^{1}\,P_{\ell}(z)f(z)\,dz$$
>
>

^legendre-coefficient

> [!def] Legendre Series
> The **Legendre series** $f(t)$ is an [[5.2 - Infinite Series#^infinite-series]] of the [[#^legendre-coeff]] $\{a_{n},b_{n}\}=\{c_{n}\}$ times the basis [[#^wxnmf0|Legendre Polynomials]] $P_{\ell}(z)$ for $\ell\in\mathbb{Z}$.
> $$\sum_{\ell=0}^{\infty}c_{\ell}\,P_{\ell}(z)$$

^legendre-series

> [!thm] Legendre's Theorem
> The [[#^legendre-series]] $P_{\ell}(z)$ is a [[2.7 - Function Spaces#^complete-orthonormal-function-basis]] spanning [[2.7 - Function Spaces#^l2-space]] $f(z)\in L^{2}$.
>
> $$f(z)=\sum_{\ell=0}^{\infty}c_{\ell}\,P_{\ell}(z)$$

^legendres-theorem
