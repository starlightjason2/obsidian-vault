# Calculus of Variations

> [!def] Lagrangian
> A [[3.1 - Scalar Functions#^function]] $\mathcal{L}$ depending on any arbitrary $x(t)$, $\frac{\partial x}{\partial t}$, and $t$.
> $$\mathcal{L}\left( x\\,\frac{\partial x}{\partial t}, \,t \right)$$

^lagrangian

> [!def] Action
> The action $S$ is the integral of the [[#^lagrangian]] over time.
> $$S=\int_{t_0}^{t_f} \mathcal{L}(x,\dot{x},t)\,dt$$

^action

> [!thm] Euler-Lagrange Equation
> Given a $\mathcal{L}(x(t),\dot{x}(t),t)$ where $\dot{x}=\frac{dx}{dt}$. The following relation is true for any **stationary** [[#^action]].
>$$
>\frac{\partial \mathcal{L}}{\partial x}=\frac{d}{dt}\left( \frac{\partial \mathcal{L}}{\partial \dot{x}} \right)
>$$

^euler-lagrange-equation

`\begin{proof}`@[[#^euler-lagrange-equation]]
We want to find the optimal path $x(t)$, and claim that this minimizes the [[#^action]]. We find the true minimum by considering paths that are **slightly off** the true path.

Call this "wrong" path $X(t)$. Let $\alpha$ quantify how "off" the path $X$ is from the true path $x$. Define $\eta(t_{1})=\eta(t_{2})=0$.

$$
\begin{align}
X(t)&=x(t)+\alpha\,\eta(t) \\
\dot{X}(t)&=\dot{x}(t)+\alpha\,\dot{\eta}(t) \\
\end{align}
$$

The new action of the wrong path is

$$
S(t)=\int_{t_0}^{t_f} \mathcal{L}(X,\dot{X},t)\,dt
$$

To find the true path, we can set $\frac{\partial S}{\partial \alpha}=0$ to find the critical point where $S$ is minimized. By the [[3.5 - Derivatives#^generalized-chain-rule]], we get the following equation (we know $t$ doesn't depend on $\alpha$, so $\frac{dt}{d\alpha}=0$)

$$
\frac{\partial S}{\partial \alpha}=\int_{t_0}^{t_f} \left( \frac{\partial \mathcal{L}}{\partial X}\,\frac{\partial X}{\partial \alpha}+\frac{\partial \mathcal{L}}{\partial \dot{X}}\frac{\partial \dot{X}}{\partial \alpha}+\cancel{\frac{\partial \mathcal{L}}{\partial t}\frac{\partial t}{\partial \alpha}} \right)\,dt=0
$$

 We see that $\frac{\partial X}{\partial \alpha}=\eta(t)$ and $\frac{\partial \dot{X}}{\partial \alpha}=\dot{\eta}(t)$, so we get the following.

$$
\frac{\partial S}{\partial \alpha}=\int_{t_0}^{t_f} \left( \frac{\partial \mathcal{L}}{\partial X}\,\eta(t)+\frac{\partial \mathcal{L}}{\partial \dot{X}}\,\dot{\eta}(t)\right)\,dt=\int_{t_0}^{t_f}\frac{\partial \mathcal{L}}{\partial X}\,\eta(t)\,dt+\int_{t_0}^{t_f}\frac{\partial \mathcal{L}}{\partial \dot{X}}\,\dot{\eta}(t)\,dt
$$

^a53bf4

Remove the $\dot{\eta}$ term using integration by parts where $u=\frac{\partial \mathcal{L}}{\partial \dot{X}}\,\eta, \ dv=\dot{\eta}\,dt, \ v=\eta(t), \ du=\frac{d}{dt}\left( \frac{\partial \mathcal{L}}{\partial \dot{X}} \right)$.

$$
\int \frac{\partial \mathcal{L}}{\partial \dot{X}}\,\eta(t)\,dt=\frac{\partial \mathcal{L}}{\partial \dot{X}}\,\dot{\eta}(t)-\int\eta\,\left( \frac{d}{dt}\frac{\partial \mathcal{L}}{\partial \dot{X}} \right)\,dt
$$

^a6b420

Substitute [[#^a6b420]] into [[#^a53bf4]],

$$
\begin{align}
\int_{t_0}^{t_f}\frac{\partial \mathcal{L}}{\partial X}\,\eta(t)\,dt+\int_{t_0}^{t_f} \left[ \frac{d}{dt}\left( \frac{\partial \mathcal{L}}{\partial \dot{X}}\,\eta(t) \right)-\eta(t)\,\frac{d}{dt}\left( \frac{\partial \mathcal{L}}{\partial \dot{X}} \right) \right]\,dt&=0 \\
\end{align}
$$

We can distribute the integral across the sums and simplify the antiderivative.

$$
\begin{align}
\int_{t_0}^{t_f}\frac{\partial \mathcal{L}}{\partial X}\,\eta(t)\,dt-\int_{t_0}^{t_f}\eta(t)\,\frac{d}{dt}\left( \frac{\partial \mathcal{L}}{\partial \dot{X}} \right)\,dt&=-{\int_{t_0}^{t_f} \cancel{\frac{d}{dt}}}\left( \frac{\partial \mathcal{L}}{\partial \dot{X}}\,\eta(t) \right)\,\cancel{dt} \\
&=-\left( \frac{\partial \mathcal{L}}{\partial \dot{X}}\,\eta(t) \right)\Bigg\vert_{t_{1}}^{t_{2}}
\end{align}
$$

Recall that the defined the *wrong path* to have the **same endpoints** as the *true path*, and set $\eta(t_{1})=\eta(t_{2})$. With this, we can simplify the right-hand side to $0$.

$$
\begin{align}
\int_{t_0}^{t_f}\frac{\partial \mathcal{L}}{\partial X}\,\eta(t)\,dt-\int_{t_0}^{t_f}\eta(t)\,\frac{d}{dt}\left( \frac{\partial \mathcal{L}}{\partial \dot{X}} \right)\,dt&=0 \\
\int_{t_0}^{t_f}\eta(t)\left[ \frac{\partial \mathcal{L}}{\partial X}-\,\frac{d}{dt}\left( \frac{\partial \mathcal{L}}{\partial \dot{X}} \right) \right]\,dt&=0
\end{align}
$$

The above relation must hold for **any** $\eta$, including non-zero values. Therefore, the other factor **must always** be zero.

$$
\frac{\partial \mathcal{L}}{\partial X}-\,\frac{d}{dt}\left( \frac{\partial \mathcal{L}}{\partial \dot{X}} \right)=0
$$

Rearrange to get the Euler-Lagrange equation.

`\end{proof}`
