# Regions

> [!def] 2D Bounded Region
> Consider a two dimensional region $D$ in $\mathbb{R}^{2}$. The two types of regions are bound **vertically** or **horizontally**.
>
> 1. $$D = \{(x,y): a < x < b,\ y_{\min}(x) \leq y \leq y_{\max}(x) \}$$
> 2. $$D = \{(x,y): x_{\min}(y) \leq x \leq x_{\max}(y),\ c \leq y \leq d\}$$
> 
> Furthermore, any Type 1 region can be rewritten as an equivalent Type 2 region, and vice versa, by solving the constraint functions for the other variable.

> [!def] 3D Bounded Region
> Consider a region $E$ in $\mathbb{R}^{3}$. Let the [[#^6b61a4]] $D_{xy},\,D_{xz},\,D_{yz}$ be its projections (or "shadows") in the $xy\,,xz\,,yz$ planes respectively. The three types of regions are bound by surfaces in $z$, $y$, or $x$.
>
> 1. $$E = \{(x,y,z): (x,y) \in D_{xy},\ z_{\min}(x,y) \leq z \leq z_{\max}(x,y) \}$$
> 2. $$E = \{(x,y,z): (x,z) \in D_{xz},\ y_{\min}(x,z) \leq y \leq y_{\max}(x,z) \}$$
> 3. $$E = \{(x,y,z): (y,z) \in D_{yz},\ x_{\min}(y,z) \leq x \leq x_{\max}(y,z) \}$$

> [!def] Simply Connected Region
> A [[#^6b61a4]] $D$ is **connected** if $\forall(P_{1},P_{2})\in D$, there exists a path with a **entirely inside D**.
>
> If for all curves $C\in D$, $C$ can be **shrunk to a point** while staying **inside $D$**, then $D$ is also **simply connected**.
