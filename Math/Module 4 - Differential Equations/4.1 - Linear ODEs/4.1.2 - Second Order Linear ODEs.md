# 4.1.2 - Second Order Linear ODEs

> [!def] 2nd Order Linear ODE
> A **second order** [[4.1.0 - Linear ODEs#^linear-ode]] is of the following form, where $f(x)$ is often called the *forcing function*.
> $$
> y''+p(x)\,y'+q(x)\,y=f(x)
> $$

^2nd-order-linear-ode

> [!def] Homogeneous 2nd Order Linear ODE
> A [[#^2nd-order-linear-ode]] that is also a [[4.1.0 - Linear ODEs#^linear-homogeneous-ode]].
> $$
> y''+p(x)\,y'+q(x)\,y=0
> $$

^homogeneous-2nd-order-linear-ode

> [!thm] General Solution of a Linear ODE
> Any second-order linear ODE with operator $\mathcal{L}$ can be transformed into a
> [[#^sturm-liouville-problem]] via an integrating factor $\mu(x)$, yielding an equivalent [[#^sturm-liouville-operator]] $\tilde{\mathcal{L}}=\mu\mathcal{L}$ in S-L form.
>
> $$\tilde{\mathcal{L}}\,y = \lambda\,w(x)\,y$$
>
> By the [[#^spectral-theorem]], the general solution is an [[5.2 - Infinite Series#^infinite-series]] over all eigenfunctions $\phi_{n}(x)$.
> $$y(x) = \sum_{n=1}^{\infty} c_n\,\phi_n(x)$$
> The coefficients $c_n$ are determined by initial or boundary conditions via the [[2.7 - Function Spaces#^functional-inner-product]], using orthogonality of $\{\phi_n\}$:
> $$c_n = \frac{\langle \phi_n,\, y_0\rangle_w}{\langle \phi_n,\,\phi_n\rangle_w} = \frac{\int_a^b \bar{\phi}_n(x)\,y_0(x)\,w(x)\,dx}{\int_a^b \bar{\phi}_n(x)\,\phi_n(x)\,w(x)\,dx}$$
>

## Spectral Theory

> [!def] Sturm-Liouville Operator
> The **Sturm-Liouville Operator** is a [[2.7 - Function Spaces#^hermitian-operator]] $\mathcal{L}$ representing a [[#^2nd-order-linear-ode]] in $y(x)$. It's defined in terms of the [[3.7 - Multiple Derivatives#^second-derivative]] for any [[3.4 - Limits#^continuous-function]] $p(x)$, $p'(x)$, and $q(x)\geq 0$.
> $$\mathcal{L}\,y(x)=-\frac{d}{dx}\!\left[p(x)\frac{dy}{dx}\right]+q(x)\,y(x)$$

^sturm-liouville-operator

> [!def] Sturm-Liouville Problem
> A **Sturm-Liouville Problem** is an eigenvalue equation for the [[#^sturm-liouville-operator]] operator $\mathcal{L}$ on a space with [[2.7 - Function Spaces#^functional-inner-product]] weighted by $w(x)>0$; let $y(x)$ be the [[2.7 - Function Spaces#^eigenfunction]] and $\lambda$ the [[2.6 - Eigenvectors and Eigenvalues#^eiegenvalue]].
>
> $$\mathcal{L}\,y = \lambda\, w(x)\, y$$
>
> The problem is completed by [[4.0 - ODEs#^2f00e2]] on $[a,b]$, which make $\mathcal{L}$ a [[2.7 - Function Spaces#^linear-operator]] on the [[3.7 - Periodic Functions#^l2-space]] over $[a,b]$.

^sturm-liouville-problem

> [!thm] Spectral Theorem
> For a regular [[#^sturm-liouville-problem]] on a finite interval $[a,b]$ with appropriate boundary conditions, the operator $\mathcal{L}$ has the following properties:
>
> 1. Every [[2.6 - Eigenvectors and Eigenvalues#^eiegenvalue]] is in [[2.2 - Subspaces#^19a139]]: $\lambda_n\in \mathbb{R}$.
> 2. The [[2.6 - Eigenvectors and Eigenvalues#^spectrum]] is a [[5.1 - Infinite Sequences#^divergent-sequence]], increasing $\lambda_1 < \lambda_2 < \lambda_3 < \cdots \to +\infty$
> 3. Each eigenfunction corresponds to distinct eigenvalues, all orthogonal with respect to the weighted inner product:
> $$\langle y_m,\, y_n\rangle_w = \int_a^b y_m(x)\,y_n(x)\,w(x)\,dx = 0 \qquad m\neq n$$
> 4. The eigenfunctions $\{y_n\}$ form a complete [[2.2 - Subspaces#^complete-orthonormal-basis]] for $L^2_w[a,b]$. Any function $f\in L^2_w[a,b]$ can be expanded as
> $$f(x) = \sum_{n=1}^{\infty} c_n\, y_n(x), \qquad c_n = \frac{\langle f,\, y_n\rangle_w}{\langle y_n,\, y_n\rangle_w}$$

^spectral-theorem

## Solution Techniques

### Reduction of Order

> [!thm] Reduction of Order
> Let there be a [[#^2nd-order-linear-ode]] of the form
>
> $$p_{0}(x)\,y''+p_{1}(x)\,y'+p_{2}(x)\,y=f(x)$$
>
> Let $y_{1}$ be a solution to the complementary [[#^homogeneous-2nd-order-linear-ode]]. Using the following formula, we can simplify to a [[4.1.1 - First Order Linear ODEs#^1st-order-linear-ode]] for $z=u'$.
>
> $$(p_{0}\,y_{1})\,z'+(2\,p_{0}\,y_{1}'+p_{1}\,y_{1})\,z=f(x)$$
>

^reduction-of-order

`\begin{proof}`@[[#^reduction-of-order]]

$$
\begin{align}
p_{0}(x)\,y''+p_{1}(x)\,y'+p_{2}(x)\,y&=f(x) \\
p_{0}\,y_{1}''+p_{1}\,y_{1}'+p_{2}\,y_{1}&=0
\end{align}
$$

Let there be a solution of the form $y=u\,y_{1}$.

$$
\begin{align}
y'&=u'\,y_{1}+y_{1}'\,u \\
y''&=u''\,y_{1}+2u'y_{1}'+y_{1}''\,u
\end{align}
$$

$$

p_{0}(x)\,(u''\,y_{1}+2u'y_{1}'+y_{1}''\,u)+p_{1}(x)\,u'\,y_{1}+y_{1}'\,u+p_{2}(x)\,y&=f(x) \\

$$

 The solution is found with the [[4.1.1 - First Order Linear ODEs#^general-solution-of-a-first-order-linear-ode]] in $z=u'$.
