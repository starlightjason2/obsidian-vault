# 4.1.2 - Second Order Linear ODEs

> [!def] 2nd Order Linear ODE
> A **second order** [[4.1.0 - Linear ODEs#^a64c8c]] is of the following form, where $f(x)$ is often called the *forcing function*.
> $$
> y''+p(x)\,y'+q(x)\,y=f(x)
> $$

^2e2986

> [!def] Homogeneous 2nd Order Linear ODE
> A [[#^2e2986]] that is also a [[4.1.0 - Linear ODEs#^a5e477]].
> $$
> y''+p(x)\,y'+q(x)\,y=0
> $$

^554323

> [!thm] General Solution of a Linear ODE
> Any second-order linear ODE with operator $\mathcal{L}$ can be transformed into a
> [[#^562d67]] via an integrating factor $\mu(x)$, yielding an equivalent [[#^701ec2]] $\tilde{\mathcal{L}}=\mu\mathcal{L}$ in S-L form.
>
> $$\tilde{\mathcal{L}}\,y = \lambda\,w(x)\,y$$
>
> By the [[#^nwo555]], the general solution is an [[5.2 - Infinite Series#^07b41c]] over all eigenfunctions $\phi_{n}(x)$.
> $$y(x) = \sum_{n=1}^{\infty} c_n\,\phi_n(x)$$
> The coefficients $c_n$ are determined by initial or boundary conditions via the [[2.7 - Function Spaces#^9dd68a]], using orthogonality of $\{\phi_n\}$:
> $$c_n = \frac{\langle \phi_n,\, y_0\rangle_w}{\langle \phi_n,\,\phi_n\rangle_w} = \frac{\int_a^b \bar{\phi}_n(x)\,y_0(x)\,w(x)\,dx}{\int_a^b \bar{\phi}_n(x)\,\phi_n(x)\,w(x)\,dx}$$
>

## Spectral Theory

> [!def] Sturm-Liouville Operator
> The **Sturm-Liouville Operator** is a [[2.7 - Function Spaces#^6146ae]] $\mathcal{L}$ representing a [[#^2e2986]] in $y(x)$. It's defined in terms of the [[3.7 - Multiple Derivatives#^204b75]] for any [[3.4 - Limits#^44db3d]] $p(x)$, $p'(x)$, and $q(x)\geq 0$.
> $$\mathcal{L}\,y(x)=-\frac{d}{dx}\!\left[p(x)\frac{dy}{dx}\right]+q(x)\,y(x)$$

^701ec2

> [!def] Sturm-Liouville Problem
> A **Sturm-Liouville Problem** is an eigenvalue equation for the [[#^701ec2]] operator $\mathcal{L}$ on a space with [[2.7 - Function Spaces#^9dd68a]] weighted by $w(x)>0$; let $y(x)$ be the [[2.7 - Function Spaces#^6cee8a]] and $\lambda$ the [[2.6 - Eigenvectors and Eigenvalues#^888169]].
>
> $$\mathcal{L}\,y = \lambda\, w(x)\, y$$
>
> The problem is completed by [[4.0 - ODEs#^2f00e2]] on $[a,b]$, which make $\mathcal{L}$ a [[2.7 - Function Spaces#^3fa82b]] on the [[3.7 - Periodic Functions#^a94a61]] over $[a,b]$.

^562d67

> [!thm] Spectral Theorem
> For a regular [[#^562d67]] on a finite interval $[a,b]$ with appropriate boundary conditions, the operator $\mathcal{L}$ has the following properties:
>
> 1. Every [[2.6 - Eigenvectors and Eigenvalues#^888169]] is in [[2.2 - Subspaces#^19a139]]: $\lambda_n\in \mathbb{R}$.
> 2. The [[2.6 - Eigenvectors and Eigenvalues#^b87cb6]] is a [[5.1 - Infinite Sequences#^c9939e]], increasing $\lambda_1 < \lambda_2 < \lambda_3 < \cdots \to +\infty$
> 3. Each eigenfunction corresponds to distinct eigenvalues, all orthogonal with respect to the weighted inner product:
> $$\langle y_m,\, y_n\rangle_w = \int_a^b y_m(x)\,y_n(x)\,w(x)\,dx = 0 \qquad m\neq n$$
> 4. The eigenfunctions $\{y_n\}$ form a complete [[2.2 - Subspaces#^81a43f]] for $L^2_w[a,b]$. Any function $f\in L^2_w[a,b]$ can be expanded as
> $$f(x) = \sum_{n=1}^{\infty} c_n\, y_n(x), \qquad c_n = \frac{\langle f,\, y_n\rangle_w}{\langle y_n,\, y_n\rangle_w}$$

^nwo555

## Solution Techniques

### Reduction of Order

> [!thm] Reduction of Order
> Let there be a [[#^2e2986]] of the form
>
> $$p_{0}(x)\,y''+p_{1}(x)\,y'+p_{2}(x)\,y=f(x)$$
>
> Let $y_{1}$ be a solution to the complementary [[#^554323]]. Using the following formula, we can simplify to a [[4.1.1 - First Order Linear ODEs#^655517]] for $z=u'$.
>
> $$(p_{0}\,y_{1})\,z'+(2\,p_{0}\,y_{1}'+p_{1}\,y_{1})\,z=f(x)$$
>

`\begin{proof}`@[[#^368f4f]]

$$
\begin{align}
p_{0}(x)\,y''+p_{1}(x)\,y'+p_{2}(x)\,y&=f(x) \\
p_{0}\,y_{1}''+p_{1}\,y_{1}'+p_{2}\,y_{1}&=0
\end{align}
$$
^33c9ee

Let there be a solution of the form $y=u\,y_{1}$.

$$
\begin{align}
y'&=u'\,y_{1}+y_{1}'\,u \\
y''&=u''\,y_{1}+2u'y_{1}'+y_{1}''\,u
\end{align}
$$
^ca5f2f

Substitute [[#^ca5f2f]] into [[#^33c9ee]].

$$
\begin{align}
p_{0}(x)\,(u''\,y_{1}+2u'y_{1}'+y_{1}''\,u)+p_{1}(x)\,u'\,y_{1}+y_{1}'\,u+p_{2}(x)\,y&=f(x) \\
(p_{0}\,y_{1})\,u''+(2\,p_{0}\,y_{1}'+p_{1}\,y_{1})\,u'+{\cancel{(p_{0}\,y_{1}''+p_{1}\,y_{1}'+p_{2}\,y_{1})\,u}}&=f(x) \\
\end{align}
$$

 The solution is found with the [[4.1.1 - First Order Linear ODEs#^ff34cc]] in $z=u'$.
`\end{proof}`
