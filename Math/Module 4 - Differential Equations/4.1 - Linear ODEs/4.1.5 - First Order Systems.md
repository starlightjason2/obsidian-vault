# 4.1.5 - First Order Systems

> [!def] First Order System
> Given a [[3.2 - Vector Functions#^c8839e|Vector Function]] $\mathbf{x}(t)\in \mathbb{R}^{n}$, a linear system of ODEs is a collection of $n$ coupled [[4.1.1 - First Order Linear ODEs#^1st-order-linear-ode|First Order Linear ODEs]]:
> $$\begin{align}
x_{1}'&=a_{11}(t)\,x_{1}+\dots+a_{1n}(t)\,x_{n}+f_{1}(t) \\
&\vdots \\
x_{n}'&=a_{n1}(t)\,x_{1}+\dots+a_{nn}(t)\,x_{n}+f_{n}(t)
\end{align}$$
> Encoding the coefficients in a [[2.2 - Matrices#^5bf009|Matrix]] $\mathbf{A}(t)$ and the forcing terms in a vector $\mathbf{f}(t)$, the system collapses into a single matrix equation:
> $$\frac{d{\mathbf{x}}}{dt}=\mathbf{A}(t)\,\mathbf{x}+\mathbf{f}(t)$$

^sysdef

## Homogeneous Systems

> [!def] Homogeneous Linear System of ODEs
> A [[#^sysdef]] where each equation is [[4.1.0 - Linear ODEs#^linear-homogeneous-ode|Homogeneous]].
> $$\frac{d\mathbf{x}}{dt}=\mathbf{A}(t)\,\mathbf{x}$$

^homogeneous-linear-system-of-odes

### Fundamental Solutions

> [!def] Fundamental Matrix
> Let $\{\mathbf{x}_{1}(t),\dots,\mathbf{x}_{n}(t)\}$ be [[4.1.0 - Linear ODEs#^fundamental-solutions|Fundamental Solutions]] of a [[#^homogeneous-linear-system-of-odes|Homogeneous Linear System]]. The **fundamental [[2.2 - Matrices#^5bf009]]** $\mathbf{\Phi}(t)$ has each fundamental solution as a column.
> $$\mathbf{\Phi}(t)=\begin{bmatrix}\mathbf{x}_{1}(t) & \dots & \mathbf{x}_{n}(t)\end{bmatrix}$$
> The general homogeneous solution is $\mathbf{x}_{h}(t)=\mathbf{\Phi}(t)\,\mathbf{c}$ for an arbitrary constant vector $\mathbf{c}\in \mathbb{R}^{n}$.

^fundamental-matrix

> [!thm] System Wronskian
> The [[4.1.0 - Linear ODEs#^adbb90|Wronskian]] of a [[#^sysdef]] is the [[2.4 - Determinants#^determinant|Determinant]] of it's [[#^fundamental-matrix|Fundamental Matrix]]. The solutions are linearly independent IFF $W(t)\neq 0$.
> $$W(t)=\det \mathbf{\Phi}(t)$$

^system-wronskian


## Inhomogeneous Systems

> [!thm] Variation of Parameters for Systems
> The general solution to the [[#^sysdef|Linear System]] $\frac{d\mathbf{x}}{dt}=\mathbf{A}(t)\,\mathbf{x}+\mathbf{f}(t)$, given a [[#^fundamental-matrix|Fundamental Matrix]] $\mathbf{\Phi}(t)$ for the homogeneous system, is:
> $$\mathbf{x}(t)=\mathbf{\Phi}(t)\,\mathbf{c}+\mathbf{\Phi}(t)\int \mathbf{\Phi}^{-1}(t)\,\mathbf{f}(t)\,dt$$
> For a [[4.1.6 - Constant Coefficient Systems#^constant-coefficient-system|Constant Coefficient System]] with initial condition $\mathbf{x}(0)=\mathbf{x}_{0}$, this becomes:
> $$\mathbf{x}(t)=e^{\mathbf{A} t}\,\mathbf{x}_{0}+\int_{0}^{t}e^{\mathbf{A}(t-s)}\,\mathbf{f}(s)\,ds$$

^variation-of-parameters-for-systems

`\begin{proof}`@[[#^variation-of-parameters-for-systems]]
Try the ansatz $\mathbf{x}(t)=\mathbf{\Phi}(t)\,\mathbf{u}(t)$. Differentiating, $\frac{d\mathbf{x}}{dt}=\dot{\mathbf{\Phi}}\,\mathbf{u}+\mathbf{\Phi}\,\dot{\mathbf{u}}=\mathbf{A}\,\mathbf{\Phi}\,\mathbf{u}+\mathbf{\Phi}\,\dot{\mathbf{u}}$, since columns of $\mathbf{\Phi}$ solve the homogeneous system. Substituting into $\frac{d\mathbf{x}}{dt}=\mathbf{A}\,\mathbf{x}+\mathbf{f}$ gives $\mathbf{\Phi}\,\dot{\mathbf{u}}=\mathbf{f}$, so $\dot{\mathbf{u}}=\mathbf{\Phi}^{-1}\,\mathbf{f}$. Integrating gives the stated form.

For the constant coefficient case, use $\mathbf{\Phi}(t)=e^{\mathbf{A} t}$ with $\mathbf{\Phi}^{-1}(t)=e^{-\mathbf{A} t}$, and $e^{\mathbf{A} t}\,e^{-\mathbf{A} s}=e^{\mathbf{A}(t-s)}$.
`\end{proof}`
