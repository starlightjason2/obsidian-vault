# 4.1.6 - Second Order Systems

> [!def] Second Order Linear System
> A coupled collection of $n$ [[4.1.2 - Second Order Linear ODEs|Second Order Linear ODEs]] in a [[3.2 - Vector Functions#^c8839e|Vector Function]] $\mathbf{x}(t)\in \mathbb{R}^{n}$.$$\begin{align}
x_{1}''&=f_{1}(t)+\sum_{j=1}^{m}a_{1j}(t)\,x_{j}+\sum_{j=1}\,b_{nj}\,x_{n} \\
&\vdots \\
x_{n}''&=f_{n}(t)+\sum_{j=1}^{m}a_{nj}(t)\,x_{j}+\sum_{j=1}\,b_{nj}\,x_{n}
\end{align}$$
> 
> Encoding the coefficients in a [[2.2 - Matrices#^5bf009|Matrix]] $\mathbf{A}(t)$ and the forcing terms in a vector $\mathbf{f}(t)$, the system collapses into a single matrix equation:
> $$\mathbf{x}''=\mathbf{A}(t)\,\mathbf{x}+\mathbf{B}(t)\,\mathbf{x}'+\mathbf{f}(t)$$
>

^sysdef2

> [!thm] Reduction to First Order
> A [[#^sysdef2|Second Order Linear System]] in $\mathbb{R}^{n}$ is equivalent to a [[4.1.6 - Second Order Systems#^sysdef|First Order Linear System]] in $\mathbb{R}^{2n}$. Stack $\mathbf{y}=\begin{bmatrix}\mathbf{x} \\ \mathbf{x}'\end{bmatrix}$:
> $$\frac{d\mathbf{y}}{dx}=\begin{bmatrix}\mathbf{0} & \mathbf{I} \\ \mathbf{A} & \mathbf{B}\end{bmatrix}\mathbf{y}+\begin{bmatrix}\mathbf{0} \\ \mathbf{f}(t)\end{bmatrix}$$
> All [[4.1.6 - Second Order Systems#^eigans|Eigenvalue]] and [[4.1.6 - Second Order Systems#^matexp-sol|Matrix Exponential]] machinery applies to the enlarged system.

^reduce21

> [!thm] Eigenvalue Solution to Second Order Systems
> For a [[#^sysdef2|Homogeneous]] [[4.1.6 - Second Order Systems#^constsys|Constant Coefficient]] system $\mathbf{x}''=\mathbf{A}\,\mathbf{x}$, the ansatz $\mathbf{x}(t)=e^{\mu t}\,\mathbf{v}$ reduces to an [[2.6 - Eigenvectors and Eigenvalues#^b325d4|Eigenvalue]] equation where each $\lambda_{i}$ contributes a pair of fundamental solutions with $\mu=\pm\sqrt{\lambda_{i}}$, doubling the dimension of the solution space to $2n$.
> $$\mathbf{A}\,\mathbf{v}=\mu^{2}\,\mathbf{v}$$
>

^eigans2

`\begin{proof}`@[[#^eigans2]]
Differentiating twice, $\mathbf{x}''=\mu^{2}\,e^{\mu t}\,\mathbf{v}$. Substituting into $\mathbf{x}''=\mathbf{A}\,\mathbf{x}$ and dividing by $e^{\mu t}\neq 0$ yields $\mu^{2}\,\mathbf{v}=\mathbf{A}\,\mathbf{v}$. The same eigenvectors of $\mathbf{A}$ work as in the first order case, but each eigenvalue $\lambda$ produces two characteristic exponents $\mu=\pm\sqrt{\lambda}$.
`\end{proof}`
