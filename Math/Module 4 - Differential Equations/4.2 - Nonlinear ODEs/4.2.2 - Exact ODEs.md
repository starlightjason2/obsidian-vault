# 4.2.2 - Exact ODEs

## Exact ODE

> [!def] Exact ODE
> An **exact ODE** is a first order [[4.0 - ODEs#^f66176]] in the form of the [[3.5 - Derivatives#^24b618]] of a function $f(x,y)$.
>
> $$\frac{\partial f}{\partial x}\,dx+\frac{\partial f}{\partial y}\,dy=0$$
>
> The equation has the following solution where $c$ is a constant.
>
> $$f(x,y)=c$$

^7eb83e

> [!thm] Exactness Condition
> Let there be an [[4.0 - ODEs#^f66176]] of the form $M(x,y)\,dx+N(x,y)\,dy=0$.
>
> The equation is an [[#^7eb83e]] on $R$ if for all $(x,y)\in R$, $\frac{\partial M}{\partial y}(x,y)=\frac{\partial N}{\partial x}(x,y)$.
> $$M(x,y)\,dx+N(x,y)\,dy=0 \text{ is an exact ODE}\iff\forall (x,y), \ \frac{\partial M}{\partial y}(x,y)=\frac{\partial N}{\partial x}(x,y)$$
>

> [!def] Integrating Factor for an Exact Equation
> A function $\mu(x,y)$ is an integrating factor that converts an equation into an [[#^7eb83e]]. So let $\mu$ be a function such that $\mu\,M\,dx+\mu\,N\,dy=0$.
>
> - If $\frac{1}{N}\left( \frac{\partial M}{\partial y}-\frac{\partial N}{\partial x} \right)$ is **only a function of $x$**, then $$\mu(x)=e^{\int\frac{1}{N}\left( \frac{\partial M}{\partial y}-\frac{\partial N}{\partial x} \right)\,dx}$$
> - If $\frac{1}{M}\left( \frac{\partial N}{\partial x}-\frac{\partial M}{\partial y} \right)$ is **only a function of $y$**, then $$\mu(y)=e^{\int\frac{1}{M}\left( \frac{\partial N}{\partial x}-\frac{\partial M}{\partial y}\right)\,dy}$$
> - Otherwise, there is no integrating factor.
